# Planet texture attribution

The eight planet surface maps in this directory are adapted from [Solar System Scope's texture library](https://www.solarsystemscope.com/textures/), licensed under [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Copyright and credit: Solar System Scope / INOVE. The site's small preview maps are used for Venus Atmosphere, Earth Day Map, Mars, Jupiter, Uranus and Neptune. Mercury and Saturn were obtained via [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Solar_System_Scope), which credits Solar System Scope, and resized by Wikimedia to 512 pixels wide.

Changes in this portfolio: the maps are cropped to circular planet shapes and shaded with CSS lighting while preserving each planet's recognizable colors. The underlying JPEG files, except for Wikimedia's resized Mercury and Saturn versions, are unmodified source previews.
